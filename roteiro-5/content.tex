\section{Pílula 1: Assincronismo e Leitura de Dados com Fetch API (GET)}\label{sec:pilula1}

\begin{conceito}{Fundamentação teórica}
Operações de rede não podem ser executadas de forma síncrona (\textit{bloqueante}), pois o navegador congelaria a tela. O JavaScript moderno utiliza \textbf{Promises} com as palavras-chave \textbf{\texttt{async}} e \textbf{\texttt{await}}. A função \textbf{\texttt{fetch(url)}} dispara a requisição e \textbf{\texttt{await resposta.json()}} converte o fluxo HTTP em objetos utilizáveis.
\end{conceito}

\begin{boxAtividade}[Mini-Exemplo 1: Leitura Assíncrona de Arquivo JSON com Fetch GET]
\textbf{Objetivo Prático:} Ler um vetor de serviços em formato JSON e preencher dinamicamente uma lista HTML na tela sem recarregar a página, com script externo e controle do DOM.
\end{boxAtividade}

\passo{1.3}{Criar a lógica assíncrona desacoplada}
\begin{boxCodigoJS}[mini-exemplos/01-fetch-get/functions.js]
// 1. Função assíncrona dedicada
async function carregarServicos(listaServicos) {
  try {
    const resposta = await fetch('dados.json');
    const servicos = await resposta.json();

    listaServicos.innerHTML = '';

    for (const servico of servicos) {
      const item = document.createElement('li');
      item.className =
        'list-group-item d-flex justify-content-between align-items-center';
      item.innerHTML =
        '<span>' + servico.nome + '</span>' +
        '<span class="badge bg-success rounded-pill">R$ ' +
        servico.preco.toFixed(2) + '</span>';
      listaServicos.appendChild(item);
    }

  } catch (erro) {
    console.error('Falha ao carregar os dados:', erro);
  }
}

// 2. Controle seguro do ciclo de vida do DOM
document.addEventListener('DOMContentLoaded', () => {
  const btnCarregar = document.getElementById('btnCarregar');
  const listaServicos = document.getElementById('listaServicos');

  btnCarregar.addEventListener('click', () => {
    carregarServicos(listaServicos);
  });
});
\end{boxCodigoJS}

\section{Pílula 2: Microbackend Flask e a Política de Mesma Origem (CORS)}\label{sec:pilula2}

\begin{conceito}{Fundamentação teórica: os três pilares do Flask}
Em uma arquitetura web moderna desacoplada, os dados são entregues por uma API RESTful remota. Na linguagem Python, o \textbf{Flask} é a ferramenta de referência devido a três características essenciais sintetizadas no quadro a seguir:
\end{conceito}

\begin{table}[H]
\centering
\small
\renewcommand{\arraystretch}{1.45}\rowcolors{2}{fundo}{white}
\begin{tabularx}{\textwidth}{RYY}
\cabecalho \cab{Pilar Conceitual} & \cab{Características e Funcionamento} & \cab{Vantagem Didática e Prática} \\
1. Filosofia "Micro" & Núcleo enxuto (\textit{lean core}) baseado no roteador \textit{Werkzeug} e no motor de templates \textit{Jinja2}. Não impõe estruturas rígidas como o Django. & Liberdade total para estruturar o código e focar exclusivamente no roteamento e no JSON. \\

3. Ciclo de Vida WSGI & Roteamento declarativo com decoradores Python: \texttt{@app.route('/api/...', methods=['GET', 'POST'])} associados a funções executáveis. & Respostas padronizadas em JSON puro via \texttt{jsonify()}, com controle explícito de status HTTP. \\

\begin{conceito}{Fundamentação teórica: os três mandamentos do envio com POST}
Enquanto requisições \textbf{GET} servem para recuperar dados, o método HTTP \textbf{POST} transfere novas informações do cliente para persistência no servidor. Para enviar objetos estruturados com a Fetch API, três etapas são mandatórias:

// 1. Função assíncrona nomeada para processar o envio
async function cadastrarNovoServico(
  evento,
  formCadastro,
  campoNome,
  campoPreco,
  feedbackPost
) {
  evento.preventDefault();

  const dadosParaEnvio = {
    nome: campoNome.value.trim(),
    preco: parseFloat(campoPreco.value)
  };

  try {
    const resposta = await fetch(
      'http://127.0.0.1:5000/api/cadastrar',
      {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify(dadosParaEnvio)
      }
    );

    // Validação explícita de status
    if (resposta.ok === false) {
      throw new Error('Erro no servidor: ' + resposta.status);
    }

    const dadosResposta = await resposta.json();

    feedbackPost.className = 'alert alert-success mb-0';
    feedbackPost.classList.remove('d-none');
    feedbackPost.innerHTML =
      '<strong>' + dadosResposta.mensagem + '</strong><br>' +
      '<small>ID gerado: #' + dadosResposta.registro.id +
      ' | Total: ' + dadosResposta.total + '</small>';

    formCadastro.reset();

  } catch (erro) {
    feedbackPost.className = 'alert alert-danger mb-0';
    feedbackPost.classList.remove('d-none');
    feedbackPost.innerHTML =
      '<strong>Falha ao enviar:</strong> ' + erro.message;
  }
}

// 2. Controle seguro de carregamento do DOM
document.addEventListener('DOMContentLoaded', () => {
  const formCadastro = document.getElementById('formCadastro');
  const campoNome = document.getElementById('campoNome');
  const campoPreco = document.getElementById('campoPreco');
  const feedbackPost = document.getElementById('feedbackPost');

  formCadastro.addEventListener('submit', (evento) => {
    cadastrarNovoServico(
      evento,
      formCadastro,
      campoNome,
      campoPreco,
      feedbackPost
    );
  });
});

\section{Pílula 4: Resiliência de Rede e Feedback Visual (try/catch/finally com Spinner)}\label{sec:pilula4}

\begin{conceito}{Fundamentação teórica: anatomia da resiliência de rede}
Falhas de conectividade (servidor offline, queda de rede, lentidão) são comuns no mundo real. Uma aplicação de qualidade profissional nunca deixa a interface congelada sem resposta.
\end{conceito}

\begin{table}[H]
\centering
\small
\renewcommand{\arraystretch}{1.45}\rowcolors{2}{fundo}{white}
\begin{tabularx}{\textwidth}{RlY}
\cabecalho \cab{Bloco / Recurso} & \cab{Momento de Disparo} & \cab{Papel na Experiência do Usuário (UX)} \\
1. Bloco \texttt{try} & Tentativa inicial de requisição & Dispara o \texttt{fetch()} e processa os dados com \texttt{await}. \\

4. Bloco \texttt{finally} & \textbf{Executado SEMPRE} & Oculta o spinner e reativa os botões para nova tentativa do usuário. \\
\end{tabularx}
\caption{Ciclo de resiliência e tratamento defensivo com try...catch...finally.}

async function cadastrarNovoServico(evento, formCadastro, campoNome, campoCategoria, campoPreco, feedbackPost) {
  evento.preventDefault();

  const dadosParaEnvio = {
    nome: campoNome.value.trim(),
    categoria: campoCategoria.value,
    preco: parseFloat(campoPreco.value)
  };

  try {
    const resposta = await fetch('http://127.0.0.1:5000/api/cadastrar', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(dadosParaEnvio)
    });

    if (resposta.ok === false) {
      throw new Error('Erro no servidor: ' + resposta.status);
    }

    const dadosResposta = await resposta.json();

    feedbackPost.className = 'alert alert-success mb-0';
    feedbackPost.classList.remove('d-none');
    feedbackPost.innerHTML =
      '<strong>' + dadosResposta.mensagem + '</strong><br>' +
      '<small>ID #' + dadosResposta.registro.id +
      ' | Categoria: ' + dadosResposta.registro.categoria +
      ' | Total: ' + dadosResposta.total + '</small>';

    formCadastro.reset();

  } catch (erro) {
    feedbackPost.className = 'alert alert-danger mb-0';
    feedbackPost.classList.remove('d-none');
    feedbackPost.innerHTML = '<strong>Falha ao enviar:</strong> ' + erro.message;
  }
}

  elementos.btnSimularErro.disabled = true;
  elementos.iconeBotao.classList.add('d-none');

function desativarEstadoCarregando(elementos) {
  elementos.spinnerCarregamento.classList.add('d-none');
  elementos.iconeBotao.classList.remove('d-none');
  elementos.textoBotao.textContent = 'Testar Conexão Oficial (/api/status)';
  elementos.btnVerificar.disabled = false;
  elementos.btnSimularErro.disabled = false;
  elementos.caixaAlerta.classList.remove('d-none');
}

async function requisitarUrlComResiliencia(urlAlvo, elementos) {
  ativarEstadoCarregando(elementos);

  try {
    const resposta = await fetch(urlAlvo);

    if (resposta.ok === false) {
      throw new Error('Código HTTP retornado pelo servidor: ' + resposta.status + ' (' + resposta.statusText + ')');
    }

    const dados = await resposta.json();
    elementos.caixaAlerta.className = 'alert alert-success mb-0';
    elementos.caixaAlerta.innerHTML =
      '<i class="bi bi-check-circle-fill me-1"></i> ' +
      '<strong>API Conectada!</strong> Servidor: ' + dados.servidor;

  } catch (erro) {
    elementos.caixaAlerta.className = 'alert alert-danger mb-0';
    elementos.caixaAlerta.innerHTML =
      '<i class="bi bi-exclamation-triangle-fill me-1"></i> ' +
      '<strong>Falha de Conectividade:</strong> ' + erro.message;

  } finally {
    // Executado SEMPRE: restaura botões e desliga o spinner!
    desativarEstadoCarregando(elementos);
  }
}
