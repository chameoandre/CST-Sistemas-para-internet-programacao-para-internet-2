\subsubsection{Pílula 1: Assincronismo e Leitura de Dados com Fetch API (GET)}

\textbf{Fundamentação Teórica:} Operações de rede não podem ser executadas de forma síncrona (\textit{bloqueante}), pois o navegador congelaria a tela. O JavaScript moderno utiliza \textbf{Promises} com as palavras-chave \textbf{\texttt{async}} e \textbf{\texttt{await}}. A função \textbf{\texttt{fetch(url)}} dispara a requisição e \textbf{\texttt{await resposta.json()}} converte o fluxo HTTP em objetos utilizáveis.

\begin{boxAtividade}[Mini-Exemplo 1: Leitura Assíncrona de Arquivo JSON com Fetch GET]
\textbf{Objetivo Prático:} Ler um vetor de serviços em formato JSON e preencher dinamicamente uma lista HTML na tela sem recarregar a página, com script externo e controle do DOM.

\textbf{Passo 1.3: Criar a lógica assíncrona desacoplada (\texttt{mini-exemplos/01-fetch-get/functions.js}):}
\begin{boxCodigoJS}
// 1. Função assíncrona dedicada
async function carregarServicos(listaServicos) {
  try {
    const resposta = await fetch('dados.json');
    const servicos = await resposta.json();

    listaServicos.innerHTML = '';

    for (const servico of servicos) {
      const item = document.createElement('li');
      item.className =
        'list-group-item d-flex justify-content-between align-items-center';
      item.innerHTML =
        '<span>' + servico.nome + '</span>' +
        '<span class="badge bg-success rounded-pill">R$ ' +
        servico.preco.toFixed(2) + '</span>';
      listaServicos.appendChild(item);
    }

  } catch (erro) {
    console.error('Falha ao carregar os dados:', erro);
  }
}

// 2. Controle seguro do ciclo de vida do DOM
document.addEventListener('DOMContentLoaded', () => {
  const btnCarregar = document.getElementById('btnCarregar');
  const listaServicos = document.getElementById('listaServicos');

  btnCarregar.addEventListener('click', () => {
    carregarServicos(listaServicos);
  });
});
\end{boxCodigoJS}

\subsubsection{Pílula 2: Microbackend Flask e a Política de Mesma Origem (CORS)}

\textbf{Fundamentação Teórica: Os Três Pilares do Microframework Flask}

Em uma arquitetura web moderna desacoplada, os dados são entregues por uma API RESTful remota. Na linguagem Python, o \textbf{Flask} é a ferramenta de referência devido a três características essenciais sintetizadas no quadro a seguir:

\vspace{0.2cm}
\begin{table}[H]
\centering
\small
\arrayrulecolor{borderGray}
\begin{tabularx}{\textwidth}{|l|X|X|}
\hline
\rowcolor{cinzaCabecalho}
\textbf{Pilar Conceitual} & \textbf{Características e Funcionamento} & \textbf{Vantagem Didática e Prática} \\ \hline
\rowcolor{cinzaLinha}
\textbf{1. Filosofia "Micro"} & Núcleo enxuto (\textit{lean core}) baseado no roteador \textit{Werkzeug} e no motor de templates \textit{Jinja2}. Não impõe estruturas rígidas como o Django. & Liberdade total para estruturar o código e focar exclusivamente no roteamento e no JSON. \\ \hline
\textbf{2. Aplicações Típicas} & APIs RESTful para Single Page Applications (SPAs), microsserviços distribuídos em nuvem e APIs preditivas para modelos de IA. & É o padrão consagrado da indústria para criar serviços rápidos, robustos e leves. \\ \hline
\rowcolor{cinzaLinha}
\textbf{3. Ciclo de Vida WSGI} & Roteamento declarativo com decoradores Python: \texttt{@app.route('/api/...', methods=['GET', 'POST'])} associados a funções executáveis. & Respostas padronizadas em JSON puro via \texttt{jsonify()}, com controle explícito de status HTTP. \\ \hline
\end{tabularx}
\caption{Visão sintetizada dos três pilares do microframework Flask.}
\end{table}

\textbf{Fundamentação Teórica: Os Três Mandamentos do Envio de Dados com POST}

Enquanto requisições \textbf{GET} servem para recuperar dados, o método HTTP \textbf{POST} transfere novas informações do cliente para persistência no servidor. Para enviar objetos estruturados com a Fetch API, três etapas são mandatórias:

\vspace{0.2cm}
\begin{table}[H]
\centering
\small
\arrayrulecolor{borderGray}
\begin{tabularx}{\textwidth}{|l|l|X|}
\hline
\rowcolor{cinzaCabecalho}
\textbf{Etapa Mandatória} & \textbf{Sintaxe de Código} & \textbf{Papel no Protocolo HTTP} \\ \hline
\rowcolor{cinzaLinha}
\textbf{1. Método Semântico} & \texttt{method: 'POST'} & Informa ao servidor que se trata de uma operação de criação/cadastro. \\ \hline
\textbf{2. Cabeçalho de Tipo} & \texttt{headers: \{ 'Content-Type': 'application/json' \}} & Avisa ao Flask que o corpo trafega codificado no padrão MIME JSON. \\ \hline
\rowcolor{cinzaLinha}
\textbf{3. Serialização} & \texttt{body: JSON.stringify(dadosParaEnvio)} & Converte o objeto JavaScript em memória em texto puro JSON para a rede. \\ \hline
\end{tabularx}
\caption{Os três mandamentos para envio de dados via Fetch API POST.}
\end{table}

// 1. Função assíncrona nomeada para processar o envio
async function cadastrarNovoServico(
  evento,
  formCadastro,
  campoNome,
  campoPreco,
  feedbackPost
) {
  evento.preventDefault();

  const dadosParaEnvio = {
    nome: campoNome.value.trim(),
    preco: parseFloat(campoPreco.value)
  };

  try {
    const resposta = await fetch(
      'http://127.0.0.1:5000/api/cadastrar',
      {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify(dadosParaEnvio)
      }
    );

    // Validação explícita de status
    if (resposta.ok === false) {
      throw new Error('Erro no servidor: ' + resposta.status);
    }

    const dadosResposta = await resposta.json();

    feedbackPost.className = 'alert alert-success mb-0';
    feedbackPost.classList.remove('d-none');
    feedbackPost.innerHTML =
      '<strong>' + dadosResposta.mensagem + '</strong><br>' +
      '<small>ID gerado: #' + dadosResposta.registro.id +
      ' | Total: ' + dadosResposta.total + '</small>';

    formCadastro.reset();

  } catch (erro) {
    feedbackPost.className = 'alert alert-danger mb-0';
    feedbackPost.classList.remove('d-none');
    feedbackPost.innerHTML =
      '<strong>Falha ao enviar:</strong> ' + erro.message;
  }
}

// 2. Controle seguro de carregamento do DOM
document.addEventListener('DOMContentLoaded', () => {
  const formCadastro = document.getElementById('formCadastro');
  const campoNome = document.getElementById('campoNome');
  const campoPreco = document.getElementById('campoPreco');
  const feedbackPost = document.getElementById('feedbackPost');

  formCadastro.addEventListener('submit', (evento) => {
    cadastrarNovoServico(
      evento,
      formCadastro,
      campoNome,
      campoPreco,
      feedbackPost
    );
  });
});
\end{boxCodigoJS}

\subsubsection{Pílula 4: Resiliência de Rede e Feedback Visual (try/catch/finally com Spinner)}

\textbf{Fundamentação Teórica: Anatomia da Resiliência de Rede}

Falhas de conectividade (servidor offline, queda de rede, lentidão) são comuns no mundo real. Uma aplicação de qualidade profissional nunca deixa a interface congelada sem resposta.

\vspace{0.2cm}
\begin{table}[H]
\centering
\small
\arrayrulecolor{borderGray}
\begin{tabularx}{\textwidth}{|l|l|X|}
\hline
\rowcolor{cinzaCabecalho}
\textbf{Bloco / Recurso} & \textbf{Momento de Disparo} & \textbf{Papel na Experiência do Usuário (UX)} \\ \hline
\rowcolor{cinzaLinha}
\textbf{1. Bloco \texttt{try}} & Tentativa inicial de requisição & Dispara o \texttt{fetch()} e processa os dados com \texttt{await}. \\ \hline
\textbf{2. Validação \texttt{ok}} & Imediatamente após a resposta & Verifica se o código HTTP é da faixa 200–299; se for falso, lança erro. \\ \hline
\rowcolor{cinzaLinha}
\textbf{3. Bloco \texttt{catch}} & Quando ocorre falha de rede/servidor & Intercepta a exceção sem quebrar o app e exibe alerta amigável. \\ \hline
\textbf{4. Bloco \texttt{finally}} & \textbf{Executado SEMPRE} & Oculta o spinner e reativa os botões para nova tentativa do usuário. \\ \hline
\end{tabularx}
\caption{Ciclo de resiliência e tratamento defensivo com try...catch...finally.}
\end{table}

// 1. Funções auxiliares para clareza visual de estados
function ativarEstadoCarregando(elementos) {
  elementos.btnVerificar.disabled = true;
  elementos.iconeBotao.classList.add('d-none');
  elementos.spinnerCarregamento.classList.remove('d-none');
  elementos.textoBotao.textContent = 'Consultando Servidor...';
  elementos.caixaAlerta.classList.add('d-none');
}

function desativarEstadoCarregando(elementos) {
  elementos.spinnerCarregamento.classList.add('d-none');
  elementos.iconeBotao.classList.remove('d-none');
  elementos.textoBotao.textContent = 'Testar Conexão com o Servidor';
  elementos.btnVerificar.disabled = false;
  elementos.caixaAlerta.classList.remove('d-none');
}

// 2. Função assíncrona nomeada com bloco defensivo try...catch...finally
async function testarConexaoComServidor(elementos) {
  ativarEstadoCarregando(elementos);

  try {
    const resposta = await fetch('http://127.0.0.1:5000/api/status');

    if (resposta.ok === false) {
      throw new Error('Código de erro HTTP: ' + resposta.status);
    }

    const dados = await resposta.json();

    elementos.caixaAlerta.className = 'alert alert-success mb-0';
    elementos.caixaAlerta.innerHTML =
      '<i class="bi bi-check-circle-fill me-1"></i> ' +
      '<strong>API Online!</strong> Conectado ao servidor (' +
      dados.servidor + ').';

  } catch (erro) {
    elementos.caixaAlerta.className = 'alert alert-danger mb-0';
    elementos.caixaAlerta.innerHTML =
      '<i class="bi bi-exclamation-triangle-fill me-1"></i> ' +
      '<strong>Falha de Conectividade:</strong> Não foi possível acessar a API.<br>' +
      '<small class="text-muted">Detalhe: ' + erro.message + '</small>';

  } finally {
    // Executado SEMPRE: desliga o spinner e reativa o botão
    desativarEstadoCarregando(elementos);
  }
}

// 3. Controle seguro de carregamento do DOM

\subsection{Mini Desafios Práticos de Fixação (Fundamentos \& Mini-Exemplos)}

Para consolidar os conceitos aprendidos nas 4 pílulas práticas de aquecimento antes de avançar para a Vitrine de Serviços, propomos \textbf{3 mini desafios progressivos e focados}. Eles foram desenhados para que você pratique pequenas alterações incrementais no backend e no frontend com total clareza.

\begin{boxDica}[Metodologia de Aprendizagem Ativa]
Tente implementar cada mini desafio no código dos mini-exemplos antes de conferir o gabarito. Observe como pequenas adições fluem entre o servidor Python e a interface no navegador!
\end{boxDica}

\subsubsection*{Mini Desafio 1: Adicionar Versão e Câmpus na API (Pílula 2)}
\textbf{Objetivo:} Praticar a extensão de um endpoint \texttt{GET} no Flask e a leitura de novos campos no frontend.
\begin{itemize}[leftmargin=*]
  \item \textbf{No Servidor (\texttt{mini-exemplos/02-micro-flask-cors/server.py}):} No endpoint \texttt{/api/status}, adicione as chaves \texttt{'versao': '1.0.0'} e \texttt{'campus': 'IFSC Garopaba'} ao dicionário retornado;
  \item \textbf{No Frontend (\texttt{mini-exemplos/02-micro-flask-cors/functions.js}):} Na função \texttt{consultarStatusApi}, exiba as informações de versão e câmpus dentro do card de alerta verde na tela.
\end{itemize}

\subsubsection*{Mini Desafio 2: Campo de Categoria no Envio com POST (Pílula 3)}
\textbf{Objetivo:} Adicionar um novo campo de seleção ao formulário de envio e persistir a informação no servidor.
\begin{itemize}[leftmargin=*]
  \item \textbf{No Formulário (\texttt{mini-exemplos/03-fetch-post/index.html}):} Adicione um campo de seleção (\texttt{select}) com \texttt{id="campoCategoria"} contendo as opções: \textit{"Tecnologia"}, \textit{"Alimentação"}, \textit{"Artesanato"} e \textit{"Serviços Gerais"};
  \item \textbf{No JavaScript (\texttt{mini-exemplos/03-fetch-post/functions.js}):} Capture o valor selecionado e adicione a propriedade \texttt{categoria} no objeto \texttt{dadosParaEnvio};
  \item \textbf{No Servidor (\texttt{mini-exemplos/03-fetch-post/server.py}):} No endpoint \texttt{/api/cadastrar}, capture o campo com \texttt{dados.get('categoria', 'Geral')} e inclua-o no dicionário \texttt{registro}.
\end{itemize}

\subsubsection*{Mini Desafio 3: Simulação de Rota com Erro 404 e Resiliência (Pílula 4)}
\textbf{Objetivo:} Comprovar o funcionamento do bloco defensivo \texttt{try...catch...finally} quando o servidor responde com código de erro HTTP (ex: 404 Não Encontrado).
\begin{itemize}[leftmargin=*]
  \item \textbf{Na Interface (\texttt{mini-exemplos/04-fetch-spinner/index.html}):} Adicione um segundo botão com estilo de contorno vermelho: \texttt{id="btnSimularErro"} com o texto \textit{"Simular Rota Inexistente (404)"};
  \item \textbf{No JavaScript (\texttt{mini-exemplos/04-fetch-spinner/functions.js}):} Adicione um ouvinte de clique que faça uma requisição para uma rota que não existe no Flask (\texttt{http://127.0.0.1:5000/api/rota-inexistente}). Observe o spinner girar, o erro ser capturado no \texttt{catch} e o botão ser reativado pelo \texttt{finally}!
\end{itemize}

async function consultarStatusApi(resultadoStatus) {
  try {
    const resposta = await fetch('http://127.0.0.1:5000/api/status');
    const dados = await resposta.json();

    resultadoStatus.className = 'alert alert-success mb-0';
    resultadoStatus.innerHTML =
      '<strong>Status:</strong> ' + dados.status + '<br>' +
      '<strong>Servidor:</strong> ' + dados.servidor + '<br>' +
      '<strong>Origem:</strong> ' + dados.cidade + '<br>' +
      '<strong>Câmpus:</strong> ' + dados.campus + '<br>' +
      '<strong>Versão:</strong> v' + dados.versao;

  } catch (erro) {
    resultadoStatus.className = 'alert alert-danger mb-0';
    resultadoStatus.innerHTML =
      '<strong>Erro de Conexão:</strong> Não foi possível acessar a API.<br>' +
      '<small>Verifique se o server.py está rodando e se o CORS está liberado.</small>';
  }
}

document.addEventListener('DOMContentLoaded', () => {

  const resultadoStatus = document.getElementById('resultadoStatus');

  });

async function cadastrarNovoServico(evento, formCadastro, campoNome, campoCategoria, campoPreco, feedbackPost) {
  evento.preventDefault();

  const dadosParaEnvio = {
    nome: campoNome.value.trim(),
    categoria: campoCategoria.value,
    preco: parseFloat(campoPreco.value)
  };

  try {
    const resposta = await fetch('http://127.0.0.1:5000/api/cadastrar', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(dadosParaEnvio)
    });

    if (resposta.ok === false) {
      throw new Error('Erro no servidor: ' + resposta.status);
    }

    const dadosResposta = await resposta.json();

    feedbackPost.className = 'alert alert-success mb-0';
    feedbackPost.classList.remove('d-none');
    feedbackPost.innerHTML =
      '<strong>' + dadosResposta.mensagem + '</strong><br>' +
      '<small>ID #' + dadosResposta.registro.id +
      ' | Categoria: ' + dadosResposta.registro.categoria +
      ' | Total: ' + dadosResposta.total + '</small>';

    formCadastro.reset();

  } catch (erro) {
    feedbackPost.className = 'alert alert-danger mb-0';
    feedbackPost.classList.remove('d-none');
    feedbackPost.innerHTML = '<strong>Falha ao enviar:</strong> ' + erro.message;
  }
}

document.addEventListener('DOMContentLoaded', () => {
  const formCadastro = document.getElementById('formCadastro');
  const campoNome = document.getElementById('campoNome');
  const campoCategoria = document.getElementById('campoCategoria');
  const campoPreco = document.getElementById('campoPreco');
  const feedbackPost = document.getElementById('feedbackPost');

  formCadastro.addEventListener('submit', (evento) => {
    cadastrarNovoServico(evento, formCadastro, campoNome, campoCategoria, campoPreco, feedbackPost);
  });
});
\end{boxCodigoJS}

from flask import Flask, jsonify, request
from flask_cors import CORS

app = Flask(__name__)
CORS(app)

servicos_cadastrados = []

@app.route('/api/cadastrar', methods=['POST'])
def cadastrar_servico():
    dados = request.get_json()
    
    if not dados or 'nome' not in dados or 'preco' not in dados:
        return jsonify({"erro": "Campos obrigatórios ausentes."}), 400

    novo_id = len(servicos_cadastrados) + 1
    registro = {
        "id": novo_id,
        "nome": str(dados['nome']).strip(),
        "categoria": str(dados.get('categoria', 'Serviços Gerais')).strip(),
        "preco": float(dados['preco'])
    }
    servicos_cadastrados.append(registro)
    print(f"[API FLASK] Novo serviço cadastrado: {registro}")

    return jsonify({
        "mensagem": "Serviço cadastrado com sucesso no servidor!",
        "registro": registro,
        "total": len(servicos_cadastrados)
    }), 201

if __name__ == '__main__':
    app.run(port=5000, debug=True)

\begin{boxAtividade}[{Passo 3.2: Atualizar o arquivo \texttt{mini-exemplos/04-fetch-spinner/functions.js}:}]
Implemente a função genérica que testa qualquer URL com tratamento defensivo e desligamento garantido no \texttt{finally}:
\end{boxAtividade}

\begin{boxCodigoJS}[]
function ativarEstadoCarregando(elementos) {
  elementos.btnVerificar.disabled = true;
  elementos.btnSimularErro.disabled = true;
  elementos.iconeBotao.classList.add('d-none');
  elementos.spinnerCarregamento.classList.remove('d-none');
  elementos.textoBotao.textContent = 'Consultando Servidor...';
  elementos.caixaAlerta.classList.add('d-none');
}

function desativarEstadoCarregando(elementos) {
  elementos.spinnerCarregamento.classList.add('d-none');
  elementos.iconeBotao.classList.remove('d-none');
  elementos.textoBotao.textContent = 'Testar Conexão Oficial (/api/status)';
  elementos.btnVerificar.disabled = false;
  elementos.btnSimularErro.disabled = false;
  elementos.caixaAlerta.classList.remove('d-none');
}

async function requisitarUrlComResiliencia(urlAlvo, elementos) {
  ativarEstadoCarregando(elementos);

  try {
    const resposta = await fetch(urlAlvo);

    if (resposta.ok === false) {
      throw new Error('Código HTTP retornado pelo servidor: ' + resposta.status + ' (' + resposta.statusText + ')');
    }

    const dados = await resposta.json();
    elementos.caixaAlerta.className = 'alert alert-success mb-0';
    elementos.caixaAlerta.innerHTML =
      '<i class="bi bi-check-circle-fill me-1"></i> ' +
      '<strong>API Conectada!</strong> Servidor: ' + dados.servidor;

  } catch (erro) {
    elementos.caixaAlerta.className = 'alert alert-danger mb-0';
    elementos.caixaAlerta.innerHTML =
      '<i class="bi bi-exclamation-triangle-fill me-1"></i> ' +
      '<strong>Falha de Conectividade:</strong> ' + erro.message;

  } finally {
    // Executado SEMPRE: restaura botões e desliga o spinner!
    desativarEstadoCarregando(elementos);
  }
}

document.addEventListener('DOMContentLoaded', () => {
  const elementos = {
    btnVerificar: document.getElementById('btnVerificar'),
    btnSimularErro: document.getElementById('btnSimularErro'),
    iconeBotao: document.getElementById('iconeBotao'),
    spinnerCarregamento: document.getElementById('spinnerCarregamento'),
    textoBotao: document.getElementById('textoBotao'),
    caixaAlerta: document.getElementById('caixaAlerta')
  };

  elementos.btnVerificar.addEventListener('click', () => {
    requisitarUrlComResiliencia('http://127.0.0.1:5000/api/status', elementos);
  });

  elementos.btnSimularErro.addEventListener('click', () => {
    requisitarUrlComResiliencia('http://127.0.0.1:5000/api/rota-inexistente', elementos);
  });
});
