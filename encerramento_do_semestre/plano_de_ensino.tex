\section{Ementa}

Conceitos avançados de desenvolvimento frontend client-side; Inclusão e integração de bibliotecas e frameworks de interface (Bootstrap 5, jQuery); Arquitetura de código JavaScript modular utilizando ES6 Modules (\texttt{import}/\texttt{export}); Manipulação avançada do DOM e formulários reativos com validação visual no cliente; Programação assíncrona avançada com \texttt{Promises}, \texttt{async/await} e consumo de APIs RESTful via \texttt{Fetch API}; Conceitos e arquitetura de Single Page Applications (SPAs) com roteamento client-side sem recarregamento de página; Gerenciamento de Estado no Cliente e armazenamento persistente via Web Storage API (\texttt{localStorage} e \texttt{sessionStorage}); Introdução às ferramentas modernas de empacotamento, build e ecossistemas frontend (\texttt{Node.js}, \texttt{npm}, \texttt{Vite}); Versionamento, publicação e hospedagem de aplicações web profissionais com Git, GitHub e GitHub Pages.

% -----------------------------------------------------
% 3. OBJETIVOS
% -----------------------------------------------------
\section{Objetivos de Aprendizagem}

\subsection{Objetivo Geral}
Capacitar os estudantes na construção de aplicações web modernas, reativas, modulares e profissionais no lado do cliente (frontend), aptas a interagir assincronamente com serviços web RESTful e preparadas para os ecossistemas industriais de desenvolvimento web.

\subsection{Objetivos Específicos}
\begin{itemize}[leftmargin=*]
    \item Integrar componentes avançados de frameworks de UI (Bootstrap 5) e utilitários de manipulação do DOM (jQuery) em layouts responsivos completos;
    \item Arquitetar projetos frontend modulares aplicando os padrões de ES6 Modules (\texttt{import}/\texttt{export}) e separação de responsabilidades;
    \item Desenvolver rotinas assíncronas utilizando \texttt{async/await} para consumo e tratamento de exceções na integração com APIs RESTful via \texttt{Fetch API};
    \item Implementar padrões de armazenamento local duradouro no navegador com a Web Storage API (\texttt{localStorage} e \texttt{sessionStorage});
    \item Projetar arquiteturas de Single Page Applications (SPA) com gerenciamento de estado e navegação client-side;
    \item Utilizar ferramentas de automação e ecossistemas web modernos (\texttt{Node.js}, \texttt{npm}, \texttt{Vite});
    \item Versionar e publicar aplicações web utilizando Git, GitHub e a plataforma GitHub Pages.
\end{itemize}

% 5. METODOLOGIA DE ENSINO

\section{Metodologia de Ensino e Aprendizagem}

As aulas serão ministradas em \textbf{laboratório de informática}, adotando uma abordagem fortemente prática e centrada no estudante (\textit{Learning by Doing} e \textit{Project-Based Learning}):

\begin{itemize}[leftmargin=*]
    \item \textbf{Exposições Diálogo-Práticas:} Apresentações conceituais interativas seguidas de demonstrações ao vivo de codificação pelo docente;
    \item \textbf{Roteiros Práticos Semanais:} Resolução de roteiros de laboratório com atividades orientadas passo a passo dispostas no repositório institucional do curso;
    \item \textbf{Desenvolvimento de Projeto Integrador:} Construção de uma aplicação web real ao longo da segunda metade do semestre;
    \item \textbf{Versionamento \& Publicação Contínua:} Utilização do \texttt{Git}, \texttt{GitHub} e \texttt{GitHub Pages} como ambiente profissional de entrega dos trabalhos acadêmicos.
\end{itemize}

\subsection{Critérios de Aprovação}
\begin{itemize}[leftmargin=*]
    \item Frequência mínima exigida de \textbf{75\%} das aulas ministradas;
    \item Média Final (\textbf{MF}) igual ou superior a \textbf{6,0 (seis)}, calculada pela média ponderada dos instrumentos de avaliação.
\end{itemize}

\subsection{Recuperação Paralela da Aprendizagem}
