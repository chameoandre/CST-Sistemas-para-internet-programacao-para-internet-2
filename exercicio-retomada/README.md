## 📌 Objetivos da Atividade
Esta atividade tem como objetivo diagnosticar e consolidar os conceitos fundamentais trabalhados na UC de **Programação para a Internet I**:
1. **Estrutura HTML5 Semântica & CSS3 Responsivo** (Flexbox/Grid, CSS Variables);
2. **Manipulação Dinâmica da Árvore DOM** (`querySelector`, `createElement`, inserção/remoção de elementos);
3. **Programação Assíncrona e Fetch API** (`async/await`, consumo de APIs REST JSON públicas);
4. **Gerenciamento de Estado no Cliente** (`localStorage` com `JSON.stringify` e `JSON.parse`).

---

## 🚀 Como Executar o Projeto

1. Abra o arquivo `index.html` em qualquer navegador web moderno (Chrome, Edge, Firefox, Safari);
2. Ou utilize a extensão **Live Server** no VS Code para rodar a aplicação localmente (`http://127.0.0.1:5500`).

## 🧪 Desafios Propostos para os Estudantes (Exercício Diagnóstico)

- [ ] **Desafio 1 (Busca por CEP):** Digitar um CEP válido de Garopaba (`88495000`) ou de sua cidade e verificar o autocompletar automático dos campos de Logradouro, Bairro, Cidade e UF.
- [ ] **Desafio 2 (Persistência):** Cadastrar 2 ou 3 clientes no formulário, recarregar a página (`F5`) e comprovar que os dados permanecem na tabela via `localStorage`.
- [ ] **Desafio 3 (Exclusão):** Clicar no botão `❌ Excluir` de um cliente específico e verificar se ele é removido da árvore DOM e do `localStorage`.
- [ ] **Desafio 4 (Desafio Extra de Evolução):** Adicionar um campo de busca/filtro por nome na tabela para filtrar os clientes cadastrados em tempo real à medida que o usuário digita no input!
