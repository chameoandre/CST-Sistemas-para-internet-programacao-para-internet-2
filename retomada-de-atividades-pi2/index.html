🎨 Bootstrap 5: Recursos de Layout & Formulários

Como estilizar elementos visuais da página observando o efeito imediato das classes:

Exemplo 1

Grid Responsivo & Containers

Em vez de criar regras CSS manuais, usamos o sistema de 12 colunas do Bootstrap:

<div class="container">
  <div class="row g-3">
    <div class="col-md-6 col-lg-4">Item 1</div>
    <div class="col-md-6 col-lg-8">Item 2</div>
  </div>
</div>
Exemplo 2

Formulários & Grupos de Entrada

Transforme um input comum em um campo moderno com rótulo e borda focada:

<div class="mb-3">
  <label class="form-label">Nome Completo</label>
  <input type="text" class="form-control" placeholder="Ana Silva">
</div>

⚡ jQuery: Recursos Funcionais (Seleção & Dados)

Aceder e manipular valores do DOM de forma direta e intuitiva com o cifrão $():

Exemplo 5

Seletores & Leitura/Escrita de Dados

O jQuery usa os mesmos seletores CSS para ler e alterar o DOM com métodos simples:

$('#nome').val() ➔ Lê o valor digitado dentro do input
$('#titulo').text('Novo Título') ➔ Altera o texto visível do elemento
$('#resultado').html('<b>Ok!</b>') ➔ Insere HTML internamente

Exemplo 5 em Código JS:

// Lendo input e escrevendo em outro elemento com jQuery
const valorNome = $('#input-nome').val();

// Atualiza o texto da mensagem na tela
$('#mensagem-boas-vindas').text(`Olá, ${valorNome}!`);

⚡ jQuery: Recursos Estéticos (Efeitos & Classes CSS)

Como criar efeitos visuais, ocultar elementos e alternar classes CSS com animações fluidas:

Exemplo 6

Efeitos Visuais & Manipulação de Classes

Animações nativas para mostrar/ocultar mensagens e alternar estados visuais:

$('#alerta').fadeIn() / fadeOut() ➔ Efeito suave de aparecer/desaparecer
$('#caixa').addClass('alert-success') ➔ Adiciona classe CSS do Bootstrap
$('#painel').toggleClass('d-none') ➔ Alterna a exibição visual do painel

Exemplo 6 em Código JS:

// Exibindo mensagem com animação fadeIn()
$('#mensagem-status')
  .removeClass('d-none')
  .addClass('alert-success')
  .text('Operação realizada com sucesso!')
  .fadeIn();

⚡ jQuery: Recursos Dinâmicos & LocalStorage

Escuta de eventos, inserção dinâmica de elementos no DOM e persistência local:

Exemplo 7

Eventos & Inserção Dinâmica no DOM

Escutar cliques e formulários para adicionar linhas na tabela dinamicamente:

$('#form-cliente').on('submit', function(e) {
  e.preventDefault();
  const nome = $('#nome').val();
  $('#tabela-corpo').append(`<tr><td>${nome}</td></tr>`);
});
Exemplo 8

Persistindo Dados Locais (LocalStorage)

Gravar e ler a lista de clientes no navegador para não perder dados ao dar F5:

// Salvar lista no LocalStorage
localStorage.setItem('clientes', JSON.stringify(lista));

// Ler lista do LocalStorage ao abrir
const dados = JSON.parse(localStorage.getItem('clientes')) || [];
