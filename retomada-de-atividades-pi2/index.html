⚙️ Do HTML Estático à Interatividade com JavaScript

Como o JavaScript transforma documentos de texto em interfaces vivas:

1️⃣

Captura de Interação

O usuário digita no input ou clica num botão. O JavaScript captura esse momento com Event Listeners (ex: blur, submit, click).

2️⃣

Leitura e Validação

O JS lê os dados digitados (input.value), faz verificações de segurança (campos obrigatórios, validação de e-mail e formato de CEP).

3️⃣

Atualização Dinâmica (DOM)

O JS altera o conteúdo HTML em tempo real (criando linhas <tr> na tabela) sem que o usuário precise dar F5 na página!

📡 A Virada de Chave: Conectando com a Web (Fetch API)

Por que uma página web precisa da Fetch API para se tornar uma aplicação profissional?

🔴 Sem Fetch API (Limitado):

O site só conhece os dados que já estão gravados no seu próprio código HTML. Se o usuário digitar um CEP, teríamos que cadastrar todos os CEPs do Brasil à mão dentro do código (impossível!).

Site Estático e Isolado

🟢 Com Fetch API (Aplicação Conectada):

Ao digitar o CEP, o navegador envia uma mensagem pela internet para o servidor do ViaCEP. Em milissegundos, o servidor responde com o endereço exato, e o JS preenche a tela automaticamente!

💡 Metáfora do Garçom: O fetch() é o garçom que vai até a cozinha (servidor ViaCEP), busca os dados e traz de volta para sua mesa sem congelar o restaurante!

🛠️ Ferramentas de Aceleração: Bootstrap 5 & jQuery

Em PI-2, não precisamos reinventar a roda para construir interfaces incríveis:

🎨

Bootstrap 5 (Potencializa o CSS3)

Framework de Estilização Pronta

Em vez de criar dezenas de regras CSS à mão, o Bootstrap nos fornece classes prontas para sistema de grid (row, col-md-6), botões estilizados (btn btn-success), cartões (card), formulários e tabelas elegantes.

⚡

jQuery (Potencializa o JavaScript)

Biblioteca de Manipulação Ágil

Simplifica radicalmente a escrita de código. Em vez de comandos longos do JS Vanilla, usamos a sintaxe ágil $('#cep').val() para ler valores e $.getJSON() para consultas de API em pouquíssimas linhas.

// Busca de CEP simples usando jQuery $.getJSON (Novo em PI-2)
$('#cep').on('blur', function() {
  const cep = $('#cep').val().replace(/\D/g, '');
  
  if (cep.length === 8) {
    $.getJSON(`https://viacep.com.br/ws/${cep}/json/`)
      .done(function(dados) {
        $('#logradouro').val(dados.logradouro || '');
        $('#cidade').val(dados.localidade || '');
        $('#uf').val(dados.uf || '');
      });
  }
});
// Busca de CEP usando a Fetch API com Async/Await
async function buscarCep(cep) {
  try {
    const response = await fetch(`https://viacep.com.br/ws/${cep}/json/`);
    const dados = await response.json();
    
    document.querySelector('#logradouro').value = dados.logradouro || '';
    document.querySelector('#cidade').value = dados.localidade || '';
  } catch (erro) {
    console.error('Erro ao consultar o CEP', erro);
  }
}
// Persistência de estado local com LocalStorage
function salvarCliente(novoCliente) {
  let lista = JSON.parse(localStorage.getItem('clientes')) || [];
  lista.push(novoCliente);
  localStorage.setItem('clientes', JSON.stringify(lista));
}
