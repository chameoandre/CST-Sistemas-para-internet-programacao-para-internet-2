🎨 Começando do Simples: Estilizando com Bootstrap 5

Como transformar um formulário comum em uma interface bonita apenas adicionando classes:

💡 O Efeito Visual das Classes Prontas:

No Bootstrap 5, não precisamos criar regras CSS do zero. Adicionamos nomes de classes direto nas tags HTML e vemos o efeito instantâneo:

  • 🔹 form-control ➔ Transforma inputs em caixas modernas com foco.
  • 🔹 btn btn-success ➔ Cria botões verdes estilizados.
  • 🔹 card p-4 ➔ Empacota o conteúdo em um painel elevado com bordas.
  • 🔹 table table-hover ➔ Formata tabelas com linhas destacadas ao passar o mouse.

Exemplo Prático HTML + Bootstrap 5:

<!-- Formulário Estilizado Rapidamente com Bootstrap -->
<div class="card p-4 shadow">
  <label class="form-label">Nome Completo</label>
  <input type="text" class="form-control" placeholder="Digite seu nome">
  
  <button class="btn btn-success mt-3">Salvar</button>
</div>

⚡ Acessando o DOM de Forma Simples com jQuery

Como o símbolo cifrão $() facilita a seleção e manipulação de elementos da página:

🔍 Familiarizando-se com Seletores jQuery:

O jQuery usa a mesma sintaxe de seletores do CSS que vocês viram em ProgWeb 1:

$('#nome') ➔ Seleciona o elemento pelo ID id="nome"
$('#nome').val() ➔ Lê o valor digitado dentro do input
$('#btn').on('click', fn) ➔ Escuta o clique no botão

Exemplo Simples de Manipulação no jQuery:

// Quando clicar no botão...
$('#btn-saudar').on('click', function() {
  // 1. Lê o nome digitado
  const nome = $('#nome').val();
  
  // 2. Escreve a mensagem na tela!
  $('#mensagem').text(`Olá, ${nome}! Seja bem-vindo!`);
});

📡 Conectando a Aplicação: O Papel das APIs Assíncronas

Após aprender a estilizar (Bootstrap) e manipular o DOM (jQuery), estendemos nossa página para a web:

🍽️ A Metáfora do Garçom (Requisição HTTP):

Ao digitar o CEP no formulário, a aplicação faz um pedido (requisição HTTP) ao serviço do ViaCEP. O garçom busca o endereço e traz o JSON de volta sem recarregar a página!

$.getJSON('https://viacep.com.br/ws/88495000/json/')

💾 Persistindo Dados no LocalStorage:

Para que os clientes cadastrados não desapareçam ao fechar o navegador, usamos o LocalStorage para gravar os dados diretamente no computador do usuário:

localStorage.setItem('clientes', JSON.stringify(lista))

💻 Guia Interativo de Código & Abas Passo a Passo

Clique nas abas para acompanhar a evolução progressiva do código:

<!-- Criando formulário rápido no Bootstrap 5 -->
<div class="row g-3">
  <div class="col-md-6">
    <label class="form-label">Nome Completo</label>
    <input type="text" class="form-control" id="nome">
  </div>
  <div class="col-md-6">
    <button type="submit" class="btn btn-success">Cadastrar</button>
  </div>
</div>
// Lendo input e reagindo a cliques com jQuery
$('#form-cliente').on('submit', function(e) {
  e.preventDefault(); // Evita recarregar a página
  
  const nome = $('#nome').val(); // Lê o input de nome
  console.log('Nome cadastrado:', nome);
});
// Consulta de CEP simples via jQuery $.getJSON
$('#cep').on('blur', function() {
  const cep = $('#cep').val().replace(/\D/g, '');
  
  if (cep.length === 8) {
    $.getJSON(`https://viacep.com.br/ws/${cep}/json/`)
      .done(function(dados) {
        $('#logradouro').val(dados.logradouro || '');
        $('#cidade').val(dados.localidade || '');
      });
  }
});
// Persistência de dados com LocalStorage
function salvarCliente(novoCliente) {
  let lista = JSON.parse(localStorage.getItem('clientes')) || [];
  lista.push(novoCliente);
  localStorage.setItem('clientes', JSON.stringify(lista));
}
