📁 Onde Incluir no Documento HTML5:

  • 🔹 Bootstrap CSS: No <head> para estilizar a página instantaneamente.
  • 🔹 jQuery & Script: Antes de fechar o </body> para não travar a tela.
  • 💡 Arquivo JS Externo (app.js): Lógica isolada em app.js mantendo o HTML limpo.

Exemplo de Inclusão no HTML:

<!-- 1. No <head>: Bootstrap 5 CSS do site getbootstrap.com -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">

<!-- 2. Antes de fechar </body>: jQuery do site code.jquery.com -->
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

<!-- 3. Script externo com a lógica da aplicação -->
<script src="app.js"></script>

🎨 Bootstrap 5: Recursos de Layout & Formulários

Como estilizar elementos visuais da página observando o efeito imediato das classes:

Exemplo 1

Grid Responsivo & Containers

<div class="container">
  <div class="row g-3">
    <div class="col-12 col-md-6 col-lg-4">Item 1</div>
    <div class="col-12 col-md-6 col-lg-8">Item 2</div>
  </div>
</div>
Exemplo 2

Formulários & Inputs

<div class="mb-3">
  <label class="form-label">E-mail</label>
  <input type="email" class="form-control" placeholder="ana@exemplo.com">
</div>
🔍 Para explorar mais no Bootstrap (Grid & Forms):
Classe / Opção Descrição & Efeito Visual
col-12 col-sm-6 Ocupa 100% no celular e 50% em telas pequenas (Small 576px).
col-md-4 col-lg-3 Ocupa 1/3 da tela em tablets e 1/4 em desktops grandes.
form-control-lg Aumenta a altura e tamanho da fonte do campo input.
form-select Aplica o estilo moderno do Bootstrap em menus <select>.
input-group Junta botões ou ícones diretamente ao lado do campo de texto.

Classe / Opção Descrição & Efeito Visual
btn-outline-danger Cria botão vazado com borda vermelha que preenche ao passar o mouse.
badge bg-primary Cria uma pequena etiqueta colorida para contadores ou status.

⚡ jQuery: Recursos Funcionais (Seleção & Dados)

Aceder e manipular valores do DOM de forma direta e intuitiva com o cifrão $():

Exemplo 5

Seletores & Leitura/Escrita no jQuery

// Lendo input e escrevendo em outro elemento
const valorNome = $('#input-nome').val();

// Atualiza o texto da mensagem na tela
$('#mensagem-boas-vindas').text(`Olá, ${valorNome}!`);
🔍 Para explorar mais no jQuery (Seletores & Dados):
Método / Seletor Descrição & Uso no Código
$('.minha-classe') Seleciona todos os elementos que possuem uma determinada classe CSS.
$('input[type="text"]') Seleciona elementos por atributo HTML (ex: inputs do tipo texto).
$(this) Refere-se ao elemento específico que disparou o evento atual.
$(el).attr('disabled', true) Lê ou desabilita atributos HTML de um elemento (ex: desativar botão).
$(el).removeAttr('disabled') Remove um atributo HTML (ex: reativar um botão).

⚡ jQuery: Recursos Estéticos (Efeitos & Classes CSS)

Como criar efeitos visuais, ocultar elementos e alternar classes CSS com animações fluidas:

Exemplo 6

Efeitos Visuais & Classes CSS no jQuery

// Exibindo alerta com animação fadeIn()
$('#mensagem-status')
  .removeClass('d-none')
  .addClass('alert-success')
  .text('Salvo com sucesso!')
  .fadeIn(300);
🔍 Para explorar mais no jQuery (Efeitos Visuais):
Método de Efeito Descrição & Efeito Visual
$(el).hide() / .show() Oculta ou exibe o elemento instantaneamente na tela.
$(el).slideUp() / .slideDown() Efeito de deslizar para cima (recolher) ou deslizar para baixo (expandir).
$(el).slideToggle() Alterna entre deslizar para cima e para baixo a cada clique.
$(el).toggleClass('d-none') Alterna a presença de uma classe CSS (adiciona se não tiver, remove se tiver).

⚡ jQuery: Recursos Dinâmicos & LocalStorage

Escuta de eventos, inserção dinâmica de elementos no DOM e persistência local:

Exemplo 7

Eventos & Inserção no DOM

$('#form').on('submit', function(e) {
  e.preventDefault();
  const nome = $('#nome').val();
  $('#tabela').append(`<tr><td>${nome}</td></tr>`);
});
Exemplo 8

Persistência no LocalStorage

localStorage.setItem('clientes', JSON.stringify(lista));
const dados = JSON.parse(localStorage.getItem('clientes')) || [];
🔍 Para explorar mais no jQuery (Manipulação do DOM):
Método DOM Descrição & Uso no Código
$(el).append(html) Insere novo conteúdo HTML no final do elemento selecionado.
$(el).prepend(html) Insere novo conteúdo HTML no início do elemento selecionado.
$(el).empty() Remove todo o conteúdo interno do elemento (útil para limpar tabelas).
$(el).remove() Remove o próprio elemento e seus filhos da árvore DOM.
$(this).closest('tr') Sobe na árvore DOM até encontrar a linha <tr> pai mais próxima.
