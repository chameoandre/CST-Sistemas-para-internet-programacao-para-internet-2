📡 Destrinchando a Fetch API de Forma Simples

O que é uma requisição assíncrona e por que usamos para buscar dados (ex: CEP)?

🍽️

1. A Metáfora do Garçom

Em um restaurante, você pede a comida ao garçom (Requisição HTTP). Você não fica congelado parado; você continua conversando. O garçom busca o prato na cozinha e traz de volta a resposta quando estiver pronto!

📦

2. O que é uma Promise?

Quando chamamos fetch(URL), o navegador nos dá uma Promessa (Promise) de que a resposta vai chegar. Não precisamos travar a página web enquanto o servidor responde.

🔄

3. Do Texto ao JSON

A resposta da API vem como texto puro. Convertemos para um Objeto JavaScript (JSON) usando .json() para podermos ler dados.logradouro ou dados.localidade diretamente.

⚡ Agilidade de Código com jQuery

Como a biblioteca jQuery simplifica a seleção de elementos, escuta de eventos e chamadas HTTP:

✨ Comparativo de Sintaxe:

1. Pegar valor de um input:

JS Vanilla: document.querySelector('#cep').value

jQuery: $('#cep').val()

2. Escutar clique no botão:

JS Vanilla: btn.addEventListener('click', fn)

jQuery: $('#btn').on('click', fn)

🌐 Requisição HTTP Simplificada ($.getJSON):

Com o jQuery, fazer uma consulta assíncrona a uma API JSON exige pouquíssimas linhas:

// Busca CEP com jQuery $.getJSON
$.getJSON(`https://viacep.com.br/ws/${cep}/json/`)
  .done(function(dados) {
    // Preenche os campos diretamente!
    $('#logradouro').val(dados.logradouro);
    $('#cidade').val(dados.localidade);
  });

// Busca de CEP usando jQuery $.getJSON (Fácil e Direto)
$('#cep').on('blur', function() {
  const cep = $('#cep').val().replace(/\D/g, '');
  
  if (cep.length === 8) {
    $.getJSON(`https://viacep.com.br/ws/${cep}/json/`)
      .done(function(dados) {
        $('#logradouro').val(dados.logradouro || '');
        $('#bairro').val(dados.bairro || '');
        $('#cidade').val(dados.localidade || '');
        $('#uf').val(dados.uf || '');
      });
  }
});
// Busca de CEP usando a Fetch API nativa do JS
async function buscarCep(cep) {
  try {
    const response = await fetch(`https://viacep.com.br/ws/${cep}/json/`);
    const dados = await response.json();
    
    document.querySelector('#logradouro').value = dados.logradouro || '';
    document.querySelector('#cidade').value = dados.localidade || '';
  } catch (erro) {
    console.error('Erro ao consultar o CEP', erro);
  }
}

// Persistência de dados com LocalStorage
function salvarCliente(cliente) {
  let lista = JSON.parse(localStorage.getItem('clientes')) || [];
  lista.push(cliente);
  localStorage.setItem('clientes', JSON.stringify(lista));
}
