🌐 Conceitos Fundamentais: O que é o DOM?

Compreendendo como o navegador representa a página e como o JavaScript/jQuery interage com ela:

Significado da Sigla DOM

DOM (Document Object Model - Modelo de Objeto do Documento) é a representação em memória (estrutura em árvore) da página web. Quando o navegador lê o HTML, ele transforma cada tag em um objeto acessível e manipulável.

Responsabilidades Principais do DOM

1. Mapeamento Hierárquico: Organiza a relação entre elementos pais e filhos (ex: <form> contendo <input>).
2. Interface de Interatividade: Fornece comandos para ler valores, modificar textos, alterar estilos CSS e escutar eventos (cliques e envios).

Como o JavaScript / jQuery Interage?

O código JS consulta a árvore usando seletores como $('#input-nome'). A partir daí, executa operações dinâmicas: lê dados (.val()), altera textos (.html()), modifica cores (.css()) e reage a eventos (.on('click')).

⚙️ Sintaxe do jQuery & O Comando $(document).ready()

Como os comandos são estruturados e por que precisamos aguardar a montagem do DOM:

A Sintaxe Básica do jQuery: $(seletor).acao()

Toda instrução jQuery segue o padrão $(seletor).acao():
• $: Atalho para acessar a biblioteca jQuery.
• seletor: String com o seletor CSS do elemento (ex: '#btn-salvar').
• acao(): Método que lê, modifica ou escuta o elemento (ex: .val(), .html(), .on()).

O que faz o $(document).ready(function() { ... })?

É o evento de inicialização segura da página. Ele garante que qualquer código JS/jQuery dentro dele só seja executado após o navegador ter terminado de ler todo o HTML e montado a árvore do DOM na memória.

Por que temos que utilizá-lo? (A causa do erro)

Se o script rodar antes de o HTML ser lido, o elemento (ex: #form-cadastro) ainda não existirá na memória RAM. O jQuery retornará um objeto nulo/vazio e os cliques ou eventos falharão silenciosamente!

Estrutura do Comando na Prática
$(document).ready(function() {
  // 🟢 O DOM já foi 100% carregado na RAM!
  // Aqui podemos manipular formulários e botões com segurança:
  $('#form-cadastro').on('submit', function(e) { ... });
});
🛑 Sem $(document).ready(): JS executa antes do HTML $\rightarrow$ $('#btn-salvar') é null $\rightarrow$ Evento de clique não funciona.
🟢 Com $(document).ready(): JS aguarda a montagem do DOM $\rightarrow$ $('#btn-salvar') é localizado com sucesso $\rightarrow$ Aplicação funciona perfeitamente!
💡 Sintaxe Abreviada Equivalente: $(function() { /* código */ });

Exemplo 6 (Passo 1: Leitura & Escrita Básica)

Base HTML Unificada & Seletores $()

Estrutura Base Inicial: Criação da página com o formulário #form-cadastro, inputs (#input-nome, #input-email), botão #btn-salvar e div de alerta #caixa-mensagem. Ao submeter, faz a leitura dos campos com .val() e escrita com .html().

  <input type="text" id="input-nome" class="form-control mb-2" placeholder="Nome">
  <input type="email" id="input-email" class="form-control mb-2" placeholder="E-mail">
  <button type="submit" id="btn-salvar" class="btn btn-primary">Salvar</button>

Exemplo 10 (📜 2. Script de Montagem & Remoção)

Comportamento em JavaScript

Uso de .append(trHtml) ao salvar e remoção do <tr> pai com .closest('tr') ao clicar em Excluir: 
$(document).ready(function() {
  $('#form-cadastro').on('submit', function(e) {
    e.preventDefault();
    const nome = $('#input-nome').val();
    const email = $('#input-email').val();

    // 1. Inserir nova linha na tabela com .append()
    const trHtml = `<tr><td>${nome}</td><td>${email}</td><td><button class="btn btn-danger btn-sm btn-excluir">Remover</button></td></tr>`;
    $('#tabela-corpo').append(trHtml);
    $('#form-cadastro')[0].reset();
  });

  // 2. Remover a linha <tr> pai ao clicar em Excluir
  $('#tabela-corpo').on('click', '.btn-excluir', function() {
    $(this).closest('tr').fadeOut(300, function() { $(this).remove(); });
  });
});
🔍 Métodos de Manipulação Dinâmica do DOM:
Método Função no DOM
$(el).append(html) Insere HTML no final do elemento selecionado (ex: final do <tbody>).
$(el).prepend(html) Insere HTML no início do elemento selecionado.
$(this).closest('tr') Sobe no DOM até encontrar o ancestral <tr> mais próximo.
$(el).remove() Remove o elemento definitivamente da árvore DOM.
$(el).empty() Limpa todo o conteúdo interno do elemento sem removê-lo.
💡 Anatomia da Exclusão $(this).closest(...):
$(this).closest('tr').fadeOut(300, function() { $(this).remove(); });
  • 1. $(this) (1º this): Refere-se ao botão .btn-excluir específico que recebeu o clique.
  • 2. .closest('tr'): Sobe na árvore hierárquica do DOM a partir do botão até achar o <tr> (linha) pai.
  • 3. .fadeOut(300, callback): Esmaece a linha por 300ms. A função interna executa após sumir visualmente.
  • 4. function() { $(this).remove(); }: No callback, o 2º this é o <tr>, excluindo-o definitivamente do HTML/DOM.

🔍 Deep Dive: Entendendo $(this), .closest() & Alternativas

Por que navegamos na árvore do DOM e como implementar a exclusão de 3 formas diferentes:

1. CONCEITO DE NAVEGAÇÃO NO DOM

Por que precisamos de $(this) e .closest()?

1. O Desafio dos Múltiplos Botões: Em tabelas dinâmicas, cada linha possui um botão .btn-excluir idêntico sem id individual. O $(this) dentro do evento captura exatamente o botão que foi clicado.

2. Subindo a Hierarquia com .closest('tr'): O botão está escondido dentro do <td>. Para apagar a linha inteira, o .closest('tr') faz o jQuery subir a árvore do DOM (de filho para pai/ancestral) até encontrar a tag <tr> envelope.

🌳 Árvore Hierárquica do DOM:
<tbody id="tabela-corpo">
  └── <tr> ◄── 2. .closest('tr') seleciona ESTA linha
      ├── <td>Maria Silva</td>
      ├── <td>maria@email.com</td>
      └── <td>
            └── <button class="btn-excluir"> ◄── 1. $(this) começa AQUI
          </td>
  </tr>
2. COMPARAÇÃO DE IMPLEMENTAÇÕES

3 Formas de Escrever a Mesma Funcionalidade:

🟢 Opção A: Variáveis Didáticas (Passo a Passo Explícito) 
// Separa cada etapa em uma variável legível
const $btn = $(this);                   // 1. Botão clicado
const $linha = $btn.closest('tr');     // 2. Linha <tr> pai

$linha.fadeOut(300, function() {
  $linha.remove();                      // 3. Remoção do DOM
});
⚡ Opção B: Sintaxe Fluente / Encadeada (Usada no Exemplo 10) 
// Tudo encadeado em uma única instrução
$(this).closest('tr').fadeOut(300, function() {
  $(this).remove(); // Note: este 2º this é o <tr>
});
💾 Opção C: Identificador data-id (Orientada a Dados — Exemplo 11) 
// HTML: <button data-id="15" class="btn-excluir">
const id = $(this).data('id');
$(`#linha-${id}`).fadeOut(300, function() { $(this).remove(); });

⚡ jQuery: Persistência no LocalStorage (Exemplo 11)

Armazenamento Permanente de Dados no Navegador com JSON.stringify() e JSON.parse():

Exemplo 11 (💾 1. Inicialização & Gravação)

Gerenciamento do LocalStorage

Leitura inicial do localStorage com JSON.parse() e gravação com JSON.stringify() ao cadastrar: 
$(document).ready(function() {
  // 1. Carrega dados salvos ou inicia array vazio []
  let clientes = JSON.parse(localStorage.getItem('lista_clientes')) || [];

  $('#form-cadastro').on('submit', function(e) {
    e.preventDefault();
    const nome = $('#input-nome').val();
    const email = $('#input-email').val();

    // 2. Adiciona ao array e salva no localStorage
    clientes.push({ nome, email });
    localStorage.setItem('lista_clientes', JSON.stringify(clientes));
    renderTabela();
  });
});
Exemplo 11 (🔄 2. Renderização & Exclusão Persistente)

Sincronização com a Tabela

Recriação automática das linhas <tr> ao abrir a página (F5) e sincronização ao excluir pelo índice: 
// 3. Renderiza a tabela lendo o array 'clientes'
function renderTabela() {
  $('#tabela-corpo').empty();
  clientes.forEach((c, index) => {
    $('#tabela-corpo').append(`
      <tr>
        <td>${c.nome}</td><td>${c.email}</td>
        <td><button class="btn btn-danger btn-sm btn-excluir" data-index="${index}">Remover</button></td>
      </tr>`);
  });
}

// 4. Exclui pelo índice do array e atualiza o storage
$('#tabela-corpo').on('click', '.btn-excluir', function() {
  const index = $(this).data('index');
  clientes.splice(index, 1);
  localStorage.setItem('lista_clientes', JSON.stringify(clientes));
  renderTabela();
});
🔍 Armazenamento Local & Serialização JSON (Recursos Adicionais):
Comando / API Descrição & Uso
localStorage.setItem(chave, valor) Salva uma chave e valor de texto no armazenamento permanente do navegador.
localStorage.getItem(chave) Recupera o valor texto associado a uma chave específica.
localStorage.removeItem(chave) Remove uma chave específica do armazenamento.
JSON.stringify(objeto) Converte um objeto ou array JS em texto no formato JSON para poder salvar.
JSON.parse(stringJSON) Converte um texto no formato JSON de volta para objeto ou array JS.

🔍 Deep Dive: Estratégia de Renderização & Persistência

Entendendo a função renderTabela() e a mudança de paradigma da manipulação do DOM:

1. MUDANÇA DE PARADIGMA (DOM vs DADOS)

Como a aplicação gerencia a tela?

❌ Exemplo 10 (Manipulação Direta do DOM):
A cada clique, alterava a tabela HTML "na raça" com .append() e .remove(). Problema: O HTML era a única fonte da verdade; ao pressionar F5, todos os dados sumiam!
✅ Exemplo 11 (Arquitetura Reativa a Dados):
A fonte da verdade é o array clientes gravado no localStorage. O código não insere linhas isoladas no HTML; ele atualiza os dados e chama renderTabela().
💡 Por que criar uma função renderTabela() própria?
  • Evita duplicação: O mesmo código redesenha a tela no F5, no envio do form e na remoção.
  • 100% de Fidelidade: A interface sempre reflete exatamente o que está salvo no localStorage.
  • Conceito Moderno: É a mesma lógica usada em frameworks como React, Vue e Angular!
2. FLUXO DO CÓDIGO E CICLO DE VIDA

Como os Dados Fluem na Aplicação:

🔄 As 3 Ações Principais do Sistema:
1. Ao Abrir a Página (F5):
  localStorage ➔ JSON.parse() ➔ renderTabela()
2. Ao Cadastrar Cliente:
  clientes.push() ➔ JSON.stringify() ➔ renderTabela()
3. Ao Clicar em Remover:
  clientes.splice(idx, 1) ➔ JSON.stringify() ➔ renderTabela()
📜 O Algoritmo da Função renderTabela(): 
function renderTabela() {
  $('#tabela-corpo').empty(); // 1. Limpa todas as linhas antigas
  
  clientes.forEach((c, index) => { // 2. Varre cada item da lista
    $('#tabela-corpo').append(`
      <tr>
        <td>${c.nome}</td><td>${c.email}</td>
        <td><button class="btn-excluir" data-index="${index}">Remover</button></td>
      </tr>`); // 3. Insere a nova linha com o data-index da posição
  });
}

$(document).ready(function() {

    $('#form-cadastro')[0].reset();

});
Adicionado em relação ao Exemplo 10: Camada de armazenamento permanente no navegador via localStorage com JSON.stringify() e JSON.parse(). 
$(document).ready(function() {
  // NOVO NO EXEMPLO 11: Carregar clientes salvos do LocalStorage
  let clientes = JSON.parse(localStorage.getItem('lista_clientes')) || [];

  function renderTabela() {
    $('#tabela-corpo').empty();
    clientes.forEach((c, index) => {
      const tr = `<tr><td>${c.nome}</td><td>${c.email}</td><td><button class="btn btn-danger btn-sm btn-excluir" data-index="${index}">Remover</button></td></tr>`;
      $('#tabela-corpo').append(tr);
    });
  }

  renderTabela();

  $('#form-cadastro').on('submit', function(e) {
    e.preventDefault();
    const nome = $('#input-nome').val();
    const email = $('#input-email').val();

    // NOVO NO EXEMPLO 11: Salvar no localStorage com JSON.stringify
    clientes.push({ nome, email });
    localStorage.setItem('lista_clientes', JSON.stringify(clientes));
    renderTabela();
  });

  $('#tabela-corpo').on('click', '.btn-excluir', function() {
    const index = $(this).data('index');
    clientes.splice(index, 1);
    localStorage.setItem('lista_clientes', JSON.stringify(clientes));
    renderTabela();
  });
});
