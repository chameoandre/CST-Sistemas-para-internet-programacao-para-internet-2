⚡ jQuery: Introdução Prática & Primeiros Passos (Exemplo 6)

Entendendo a Inclusão da Biblioteca, a Inicialização com $(document).ready() e a Anatomia dos Comandos:

Exemplo 6 (Primeiro Passo no jQuery)

Inclusão, $(document).ready() & Seletores

O que está sendo desenvolvido: Passo a passo inicial de uso da biblioteca. 1. Incluímos a biblioteca via CDN (jquery-3.7.1.min.js); 2. Aguardamos o HTML ser completamente renderizado com $(document).ready(); 3. Usamos o cifrão $() para selecionar ($('#id')), ler (.val()) e escrever na tela (.text()). 
<!-- 1. Inclusão do jQuery via CDN antes de fechar o </body> -->
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

<script>
  // 2. Inicialização Segura: Aguarda o HTML estar 100% pronto
  $(document).ready(function() {

    // 3. Escuta evento e manipula o DOM ($seletor.método)
    $('#btn-saudar').on('click', function() {
      const nomeDigitado = $('#input-nome').val(); // Lê input

      if (nomeDigitado.trim() === '') {
        $('#caixa-mensagem')
          .removeClass('alert-secondary alert-success')
          .addClass('alert-warning')
          .text('⚠️ Por favor, digite um nome antes de clicar!');
      } else {
        $('#caixa-mensagem')
          .removeClass('alert-secondary alert-warning')
          .addClass('alert-success')
          .html(`🎉 <strong>Sucesso!</strong> Olá <u>${nomeDigitado}</u>, o jQuery leu seu nome!`);
      }
    });

  });
</script>
🔍 As 3 Etapas Fundamentais para Usar o jQuery:
Etapa Comando & Função Pedagógica
1. Inclusão CDN <script src="jquery.min.js">: Carrega a biblioteca e cria o atalho global $().
2. Espera do DOM $(document).ready(...): Garante que os elementos HTML já foram carregados antes de serem acessados.
3. Seletor + Ação $('#nome').val(): Seleciona o elemento pelo ID #nome e executa o método de leitura .val().
4. Escrita na Tela $('#msg').text('...') ou .html('...'): Atualiza dinamicamente o texto ou HTML de um elemento.

Efeitos Visuais & Classes CSS

O que está sendo desenvolvido: Feedback visual animado ao usuário. Remove a classe d-none para tornar o alerta visível, aplica a classe de cor alert-success do Bootstrap, altera a mensagem com .text() e faz o quadro surgir suavemente com .fadeIn(300).

🔍 Para explorar mais no jQuery (Efeitos Visuais):
Método de Efeito Descrição & Efeito Visual
$(el).hide() / .show() Oculta ou exibe o elemento instantaneamente na tela.
$(el).slideUp() / .slideDown() Efeito de deslizar para cima (recolher) ou deslizar para baixo (expandir).
$(el).slideToggle() Alterna entre deslizar para cima e para baixo a cada clique.
$(el).toggleClass('d-none') Alterna a presença de uma classe CSS (adiciona se não tiver, remove se tiver).

⚡ jQuery: Recursos Dinâmicos & LocalStorage

Escuta de eventos, inserção dinâmica de elementos no DOM e persistência local:

Exemplo 8

Eventos & Inserção Dinâmica no DOM

O que está sendo desenvolvido: Inserção de linhas na tabela via formulário. Escuta o evento submit do formulário, impede a atualização da página com e.preventDefault(), monta uma linha HTML (<tr><td>...</td></tr>) e a insere no final da tabela com .append(). 
$('#form').on('submit', function(e) {
  e.preventDefault();
  const nome = $('#nome').val();
  $('#tabela').append(`<tr><td>${nome}</td></tr>`);
});
Exemplo 9

Persistência no LocalStorage

O que está sendo desenvolvido: Armazenamento duradouro no navegador. Salva a lista de clientes convertendo para texto com JSON.stringify() e recupera os dados salvos convertendo de volta para objeto/array com JSON.parse() para os dados não sumirem ao pressionar F5. 
localStorage.setItem('clientes', JSON.stringify(lista));
const dados = JSON.parse(localStorage.getItem('clientes')) || [];
🔍 Para explorar mais no jQuery (Manipulação do DOM):
Método DOM Descrição & Uso no Código
$(el).append(html) Insere novo conteúdo HTML no final do elemento selecionado.
$(el).prepend(html) Insere novo conteúdo HTML no início do elemento selecionado.
$(el).empty() Remove todo o conteúdo interno do elemento (útil para limpar tabelas).
$(el).remove() Remove o próprio elemento e seus filhos da árvore DOM.
$(this).closest('tr') Sobe na árvore DOM até encontrar a linha <tr> pai mais próxima.
