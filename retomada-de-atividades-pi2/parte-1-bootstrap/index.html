🔍 Para explorar mais no Bootstrap (Grid & Forms):
Classe / Opção Descrição & Efeito Visual
col-12 col-sm-6 Ocupa 100% no celular e 50% em telas pequenas (Small 576px).
col-md-4 col-lg-3 Ocupa 1/3 da tela em tablets e 1/4 em desktops grandes.
form-control-lg Aumenta a altura e tamanho da fonte do campo input.
form-select Aplica o estilo moderno do Bootstrap em menus <select>.
input-group Junta botões ou ícones diretamente ao lado do campo de texto.

O que está sendo desenvolvido (Exemplo 6): Primeiro Passo Didático com jQuery. Explica as 3 etapas essenciais: 1. Inclusão do script via CDN; 2. Espera da inicialização do DOM com $(document).ready(); 3. Anatomia do comando (selecionar com $('#id'), ler com .val() e escrever na tela com .text()). 
<!-- 1. Inclusão da Biblioteca jQuery via CDN (antes de fechar o </body>) -->
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

<script>
  // 2. Inicialização Segura: Aguarda o documento HTML estar 100% pronto!
  $(document).ready(function() {

    // 3. Escuta evento de clique e manipula o DOM ($seletor.ação)
    $('#btn-saudar').on('click', function() {
      const nomeDigitado = $('#input-nome').val(); // Lê input

      if (nomeDigitado.trim() === '') {
        $('#caixa-mensagem')
          .removeClass('alert-secondary alert-success')
          .addClass('alert-warning')
          .text('⚠️ Por favor, digite um nome antes de clicar!');
      } else {
        $('#caixa-mensagem')
          .removeClass('alert-secondary alert-warning')
          .addClass('alert-success')
          .html(`🎉 <strong>Sucesso!</strong> Olá <u>${nomeDigitado}</u>, o jQuery leu seu nome!`);
      }
    });

  });
</script>

<!-- 1. Inclusão da Biblioteca jQuery via CDN (antes de fechar o </body>) -->
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

<script>
  // 2. Inicialização Segura: Aguarda o documento HTML estar 100% pronto!
  $(document).ready(function() {

    // 3. Escuta evento de clique e manipula o DOM ($seletor.ação)
    $('#btn-saudar').on('click', function() {
      const nomeDigitado = $('#input-nome').val(); // Lê input

      if (nomeDigitado.trim() === '') {
        $('#caixa-mensagem')
          .removeClass('alert-secondary alert-success')
          .addClass('alert-warning')
          .text('⚠️ Por favor, digite um nome antes de clicar!');
      } else {
        $('#caixa-mensagem')
          .removeClass('alert-secondary alert-warning')
          .addClass('alert-success')
          .html(`🎉 <strong>Sucesso!</strong> Olá <u>${nomeDigitado}</u>, o jQuery leu seu nome!`);
      }
    });

  });
</script>
