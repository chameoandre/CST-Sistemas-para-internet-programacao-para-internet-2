\section{Roteiro Prático 01 — Retomada de Conteúdos: Fetch API, Bootstrap 5 e jQuery}

% =====================================================
% OBJETIVOS
% =====================================================

\begin{boxObjetivos}
\textbf{Objetivos da Aula}

Ao final desta aula o estudante será capaz de:

\begin{itemize}
\item Compreender o funcionamento das requisições assíncronas e a lógica da \texttt{Fetch API};
\item Agilizar a manipulação do DOM e escuta de eventos utilizando a biblioteca \texttt{jQuery};
\item Estruturar layouts visuais modernos e responsivos utilizando os componentes do \texttt{Bootstrap 5};
\item Persistir e manipular dados no navegador utilizando o \texttt{localStorage API};
\item Desenvolver uma aplicação web integrada de cadastro e consulta de CEP (ViaCEP).
\end{itemize}
\end{boxObjetivos}

% =====================================================
% INTRODUÇÃO
% =====================================================

\subsection{Introdução}

Bem-vindos à disciplina de \textbf{Programação para a Internet II}!

Neste primeiro encontro, faremos uma recapitulação prática das competências trabalhadas no semestre anterior (PI-I), desmistificando o uso de **requisições assíncronas (Fetch API / HTTP)** e introduzindo duas ferramentas indispensáveis para aumentar a produtividade no desenvolvimento frontend: **Bootstrap 5** (para estilização e grid responsivo) e **jQuery** (para manipulação simplificada do DOM e requisições \texttt{\$.getJSON}).

O trabalho é guiado pela \textbf{Apresentação Interativa Web} projetada em sala (\texttt{retomada-de-atividades-pi2/index.html}) e pela execução do projeto prático na pasta \texttt{exercicio-retomada/}.

% =====================================================
% PARTE 1
% =====================================================

\subsection{Parte 1 — Apresentação Interativa e Conceitos Fundamentais (20 minutos)}

\begin{boxAtividade}[{Atividade 1 -- Projeção dos Slides e Desmistificação da Fetch API}]

Acompanhamento da apresentação em slides dinâmicos (\texttt{retomada-de-atividades-pi2/index.html}):

\begin{enumerate}
\item \textbf{A Metáfora do Garçom (Slide 2):} Entendimento de como uma requisição HTTP assíncrona busca dados sem travar a interface do usuário;
\item \textbf{Produtividade com Bootstrap 5 (Slide 3):} Uso do sistema de grid (\texttt{row}, \texttt{col-md-6}) e componentes visuais prontos (\texttt{btn}, \texttt{card}, \texttt{alert}, \texttt{table});
\item \textbf{Sintaxe Ágil com jQuery (Slide 4):} Seleção simplificada (\texttt{\textdollar('\#id').val()}) e requisição direta com \texttt{\textdollar.getJSON()};
\item \textbf{Guia Interativo de Código (Slide 5):} Análise comparativa das abas de código entre Fetch API nativa, jQuery e Bootstrap 5.
\end{enumerate}

\end{boxAtividade}

% =====================================================
% PARTE 2
% =====================================================

\subsection{Parte 2 — Tarefa Prática: Dashboard de Cadastro com Bootstrap 5 e jQuery (50 minutos)}

\begin{boxAtividade}[{Atividade 2 -- Execução do Exercício na Pasta exercicio-retomada/}]

Na pasta \texttt{exercicio-retomada/}, os estudantes deverão construir/completar a aplicação web:

\begin{enumerate}
\item \textbf{Estruturação HTML5 com Bootstrap 5:} Incluir as dependências via CDN no \texttt{index.html} e utilizar as classes de formulário e tabela do Bootstrap;
\item \textbf{Busca de CEP com jQuery:} No arquivo \texttt{app.js}, implementar a função assíncrona consumindo a API ViaCEP via \texttt{\textdollar.getJSON()};
\item \textbf{Cadastro e Persistência:} Salvar os clientes cadastrados no \texttt{localStorage} (\texttt{JSON.stringify}) e atualizar a tabela via manipulação jQuery (\texttt{\textdollar('\#tabela-body').append()});
\item \textbf{Leitura e Exclusão:} Ler o \texttt{localStorage} ao iniciar a página e permitir excluir registros individualmente.
\end{enumerate}

\end{boxAtividade}

% =====================================================
% PARTE 3
% =====================================================

\subsection{Parte 3 — Desafio Extra: Filtro Dinâmico em Tempo Real (30 minutos)}

\begin{boxAtividade}[{Atividade 3 -- Filtro por Nome com jQuery}]

Como atividade de aprimoramento em sala:

\begin{enumerate}
\item Adicionar um campo de busca por nome sobre a tabela de clientes (\texttt{\textdollar('\#filtro-nome')});
\item Implementar o evento \texttt{input} do jQuery para filtrar dinamicamente as linhas exibidas à medida que o usuário digita.
\end{enumerate}

\end{boxAtividade}

% =====================================================
% CHECKLIST
% =====================================================

\subsection{Checklist Final da Aula}

\begin{boxAtividade}[{Verificação Técnica}]

Antes de finalizar o encontro, verifique se seu projeto atende aos critérios de aceitação:

\begin{itemize}
\item A página possui layout estilizado e responsivo com Bootstrap 5;
\item O preenchimento do CEP realiza requisição assíncrona (\texttt{\textdollar.getJSON} / \texttt{fetch}) e autocompleta o endereço sem reload;
\item O cadastro adiciona o novo cliente na tabela dinamicamente usando jQuery;
\item Os dados persistem no \texttt{localStorage} mesmo após recarregar a página (\texttt{F5});
\item O filtro por nome e a exclusão individual funcionam perfeitamente.
\end{itemize}

\end{boxAtividade}

% =====================================================
% REFLEXÃO TÉCNICA

\subsection*{Reflexão Técnica}

A combinação de utilitários de estilo (Bootstrap 5) com manipulação de eventos e requisições HTTP assíncronas (jQuery / Fetch API) transforma a produtividade no desenvolvimento web frontend. Entender essa dinâmica é o trampolim para avançarmos rumo aos módulos de ES6 Modules e bibliotecas de interface reativa neste semestre!
