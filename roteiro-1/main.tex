\section{Roteiro Prático 01 — Retomada e Transição: De PI-I às APIs Assíncronas, Bootstrap 5 e jQuery}

% =====================================================
% OBJETIVOS
% =====================================================

\begin{boxObjetivos}
\textbf{Objetivos da Aula}

Ao final desta aula o estudante será capaz de:

\begin{itemize}
\item Conectar a base de HTML5, CSS3 e DOM construída em PI-I com o avanço do desenvolvimento web em PI-II;
\item Compreender o papel da \texttt{Fetch API} e das requisições assíncronas na criação de aplicações web conectadas;
\item Utilizar componentes e o sistema de grid do \texttt{Bootstrap 5} para estilização responsiva ágil;
\item Empregar a biblioteca \texttt{jQuery} para simplificação da manipulação do DOM e requisições \texttt{\textdollar.getJSON()};
\item Desenvolver uma aplicação web integrada com autocompletar de CEP (ViaCEP) e persistência em \texttt{localStorage}.
\end{itemize}
\end{boxObjetivos}

% =====================================================
% INTRODUÇÃO
% =====================================================

\subsection{Introdução}

Bem-vindos à disciplina de \textbf{Programação para a Internet II}!

Neste primeiro encontro, construímos uma ponte direta entre os conceitos trabalhados no semestre anterior (HTML5 semântico, CSS3, Flexbox/Grid e seleções básicas do DOM) e a evolução para aplicações web dinâmicas. Desmistificamos a **Fetch API / requisições assíncronas** e apresentamos o **Bootstrap 5** e o **jQuery** como ferramentas de aceleração.

O trabalho é guiado pela \textbf{Apresentação Interativa de Transição} projetada em sala (\texttt{retomada-de-atividades-pi2/index.html}) e pela execução do projeto prático em \texttt{exercicio-retomada/}.

% =====================================================
% PARTE 1
% =====================================================

\subsection{Parte 1 — Apresentação Interativa de Transição (25 minutos)}

\begin{boxAtividade}[{Atividade 1 -- Projeção da Apresentação de Slides (retomada-de-atividades-pi2/index.html)}]

Acompanhamento da apresentação em slides dinâmicos:

\begin{enumerate}
\item \textbf{A Jornada de PI-I (Slide 2):} Recapitulação de HTML5 semântico, CSS3, responsividade e versionamento no Git/GitHub;
\item \textbf{Do Estático ao Reativo (Slide 3):} O papel da manipulação do DOM e da escuta de eventos na interatividade;
\item \textbf{A Virada de Chave -- Fetch API (Slide 4):} Desmistificação da Fetch API com a Metáfora do Garçom e envio/recebimento de dados JSON;
\item \textbf{Ferramentas de Aceleração (Slide 5):} Apresentação do Bootstrap 5 (grid e componentes) e do jQuery (sintaxe \texttt{\textdollar()} e \texttt{\textdollar.getJSON()});
\item \textbf{Roadmap do Semestre (Slide 6):} Visão geral da evolução em 5 módulos até o uso de ferramentas modernas como Vite e React.
\end{enumerate}

\end{boxAtividade}

% =====================================================
% PARTE 2
% =====================================================

\subsection{Parte 2 — Tarefa Prática: Dashboard com Bootstrap 5, jQuery e ViaCEP (50 minutos)}

\begin{boxAtividade}[{Atividade 2 -- Execução na Pasta exercicio-retomada/}]

Na pasta \texttt{exercicio-retomada/}, os estudantes deverão construir/completar a aplicação web:

\begin{enumerate}
\item \textbf{Estrutura Bootstrap 5:} Incluir as dependências via CDN no \texttt{index.html} e utilizar formulários e tabela estilizada do Bootstrap;
\item \textbf{Busca Assíncrona de CEP:} Implementar a chamada à API ViaCEP via \texttt{\textdollar.getJSON()} no \texttt{app.js};
\item \textbf{Persistência com LocalStorage:} Salvar os dados do cliente no \texttt{localStorage} (\texttt{JSON.stringify}) e renderizar na tabela via jQuery;
\item \textbf{Exclusão Individual:} Permitir remover registros salvos atualizando a tabela e o \texttt{localStorage}.
\end{enumerate}

\end{boxAtividade}

% =====================================================
% PARTE 3
% =====================================================

\subsection{Parte 3 — Desafio Extra: Filtro Dinâmico com jQuery (25 minutos)}

\begin{boxAtividade}[{Atividade 3 -- Filtro por Nome em Tempo Real}]

Como atividade de aprimoramento em sala:

\begin{enumerate}
\item Adicionar um campo de busca por nome sobre a tabela de clientes (\texttt{\textdollar('\#filtro-nome')});
\item Implementar o evento \texttt{input} do jQuery para filtrar dinamicamente as linhas exibidas à medida que o usuário digita.
\end{enumerate}

\end{boxAtividade}

\subsection{Checklist Final da Aula}

\begin{boxAtividade}[{Verificação Técnica}]

Antes de finalizar o encontro, verifique se seu projeto atende aos critérios de aceitação:

\begin{itemize}
\item O projeto faz uso das classes de grid e formulário do Bootstrap 5;
\item A busca de CEP é assíncrona e preenche a rua, bairro, cidade e UF sem recarregar a página;
\item O cadastro insere o cliente na tabela dinâmica usando jQuery;
\item Os dados persistem no \texttt{localStorage} mesmo após fechar ou recarregar o navegador (\texttt{F5});
\item O filtro por nome e o botão de exclusão funcionam perfeitamente.
\end{itemize}

\end{boxAtividade}

% =====================================================
% REFLEXÃO TÉCNICA
% =====================================================

\subsection*{Reflexão Técnica}

A transição da web estática (HTML/CSS) para o desenvolvimento de aplicações conectadas é marcada pela compreensão do assincronismo. Dominar a integração entre bibliotecas visuais (Bootstrap 5), manipuladores ágeis (jQuery) e consumo de APIs externas (Fetch API / \texttt{\textdollar.getJSON}) é o alicerce para construir arquiteturas profissionais no cliente!
