\section{Roteiro Prático 01 — Retomada de Conteúdos: DOM, Assincronismo e Persistência Local}

% =====================================================
% OBJETIVOS
% =====================================================

\begin{boxObjetivos}
\textbf{Objetivos da Aula}

Ao final desta aula o estudante será capaz de:

\begin{itemize}
\item Reativar os conceitos fundamentais de HTML5 semântico e CSS3 (Flexbox/Grid);
\item Manipular a árvore DOM e gerenciar eventos de formulário dinamicamente com JavaScript ES6+;
\item Realizar requisições assíncronas a APIs REST públicas utilizando \texttt{fetch} e \texttt{async/await};
\item Persistir, recuperar e remover dados no navegador utilizando a \texttt{localStorage API};
\item Desenvolver uma aplicação web completa de gestão e consulta integrada.
\end{itemize}
\end{boxObjetivos}

% =====================================================
% INTRODUÇÃO
% =====================================================

\subsection{Introdução}

Bem-vindos à disciplina de \textbf{Programação para a Internet II}!

Neste primeiro encontro, faremos uma recapitulação prática das competências trabalhadas no semestre anterior (PI-I). O trabalho é guiado pela \textbf{Apresentação Interativa Web} projetada em sala (\texttt{retomada-de-atividades-pi2/index.html}) e pela execução do projeto prático em \texttt{exercicio-retomada/}.

% =====================================================
% PARTE 1
% =====================================================

\subsection{Parte 1 — Apresentação Interativa e Visão Geral da Disciplina (15 minutos)}

\begin{boxAtividade}[{Atividade 1 -- Abertura da Aula e Projeção dos Slides}]

Acompanhamento da apresentação em slides dinâmicos (\texttt{retomada-de-atividades-pi2/index.html}):

\begin{enumerate}
\item \textbf{Boas-Vindas e Expectativas:} Visão dos 5 módulos estruturantes de PI-II (Slides 1 e 2);
\item \textbf{Recapitulando PI-I (Slide 3):} Tríade HTML5 semântico, CSS3 responsivo, manipulação do DOM, Fetch API e Web Storage;
\item \textbf{Guia Interativo de Código (Slide 5):} Revisão prática da sintaxe de \texttt{async/await}, \texttt{localStorage} e escuta de eventos.
\end{enumerate}

\end{boxAtividade}

% =====================================================
% PARTE 2
% =====================================================

\subsection{Parte 2 — Tarefa Prática: Dashboard de Cadastro e Consulta ViaCEP (55 minutos)}

\begin{boxAtividade}[{Atividade 2 -- Execução do Exercício de Retomada}]

Na pasta \texttt{exercicio-retomada/}, os estudantes deverão construir/completar a aplicação web:

\begin{enumerate}
\item \textbf{Interface HTML/CSS:} Garantir a marcação semântica e os estilos responsivos;
\item \textbf{Busca Assíncrona de CEP:} Implementar a função \texttt{async function buscarCep(cep)} consumindo a API ViaCEP ao digitar o CEP;
\item \textbf{Cadastro e Persistência:} Salvar os clientes cadastrados no \texttt{localStorage} (\texttt{JSON.stringify}) e atualizar a tabela no DOM;
\item \textbf{Carregamento e Exclusão:} Ler o \texttt{localStorage} ao iniciar a página e permitir excluir registros individualmente.
\end{enumerate}

\end{boxAtividade}

% =====================================================
% PARTE 3
% =====================================================

\subsection{Parte 3 — Desafio Extra e Validação em Sala (30 minutos)}

\begin{boxAtividade}[{Atividade 3 -- Desafio de Filtro Dinâmico}]

Como atividade de aprimoramento em sala:

\begin{enumerate}
\item Adicionar um campo de busca por nome sobre a tabela de clientes;
\item Implementar o evento \texttt{input} para filtrar dinamicamente as linhas exibidas na tabela à medida que o usuário digita.
\end{enumerate}

\end{boxAtividade}

% =====================================================
% CHECKLIST
% =====================================================

\subsection{Checklist Final da Aula}

\begin{boxAtividade}[{Verificação Técnica}]

Antes de finalizar o encontro, verifique se seu projeto atende aos critérios de aceitação:

\begin{itemize}
\item A página possui marcação HTML5 semântica e estilização CSS responsiva em Flexbox/Grid;
\item O preenchimento do CEP realiza requisição \texttt{fetch} e autocompleta os campos de endereço sem recarregar a página;
\item O cadastro adiciona o novo cliente na tabela dinamicamente via manipulação do DOM;
\item Os dados persistem no \texttt{localStorage} mesmo após fechar ou recarregar o navegador;
\item A remoção de registros funciona corretamente atualizando o estado persistido.
\end{itemize}

\end{boxAtividade}

% =====================================================
% REFLEXÃO TÉCNICA
% =====================================================

\subsection*{Reflexão Técnica}

Aplicações web modernas fundamentam-se no domínio do assincronismo e na gestão de estado client-side. Dominar a manipulação limpa do DOM, o tratamento de respostas HTTP JSON e a persistência local é o requisito básico para avançarmos em direção aos frameworks reativos (React, Vue) e arquiteturas de Single Page Application (SPA) neste semestre!
