Passo a Passo Didático do jQuery neste Exemplo
  1. Etapa 1 (Inclusão): Carregamos a biblioteca jQuery via CDN (jquery-3.7.1.min.js) antes de fechar a tag </body>. Isso cria a função global $().
  2. Etapa 2 (Inicialização Segura): Envolvemos nosso código dentro de $(document).ready(function() { ... }). Isso garante que o navegador já leu todo o HTML e os elementos #input-nome e #btn-saudar já existem antes do código tentar acessá-los.
  3. Etapa 3 (Anatomia do Comando): Usamos $('#input-nome').val() para ler o texto do campo e $('#caixa-mensagem').text('...') para escrever o resultado na tela.
